# SOP-02: Voltage Drop and Reactance Controls

## 1. Overview
This operating procedure governs grid voltage control. Standard grid nominal voltage is 220.0V. A voltage drop below 215.0V indicates heavy inductive loading or reactive power shortage.

## 2. Operational Procedures
1. **Incremental Voltage Adjustment:** Voltage settings must be adjusted incrementally. The maximum voltage adjustments per single transaction MUST NOT exceed 5% of nominal values (i.e. maximum adjustment step of 11.0V).
2. **Capacitor Banks Integration:** Toggle capacitive support grids or adjust transformer tap settings to raise the system voltage profile.
3. **Generation Mix Balancing:** Boost active generation from stable sources (e.g. Reactor Core Gamma) to support system voltage.
