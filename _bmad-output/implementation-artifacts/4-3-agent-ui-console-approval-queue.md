# Story 4.3: Agent UI Console Approval Queue

Status: done

## Story

As a SCADA Grid Operator,
I want an interactive AI Console in the dashboard,
so that I can approve or reject recommendations generated by the agent.

## Acceptance Criteria

1. Create a beautiful UI console panel matching the dashboard's retro-futuristic dark mode theme.
2. The panel shows the AI Agent's active mode (`Advisory` or `Autonomous`) and a toggle button to switch modes.
3. If an active proposal is stashed in memory (due to a grid anomaly), the console displays the proposed control action, a detailed textual justification (reasoning), and cited references from the operating manuals (RAG snippets).
4. Provides standard `Approve & Execute` and `Reject Command` buttons that dispatch POST requests to the backend.
5. Displays a historical list of past reasoning thought cycles (agent logs).
6. Automatically checks and updates proposal states periodically.
